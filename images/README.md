# Local test catalog image review

The earlier set of ten category illustrations has been retired. The local
catalog now uses item-specific candidate images under
[`catalog-review/`](catalog-review/README.md), with source and license metadata
recorded in `catalog-review/sources.json`.

These are test catalog references, not proof of the condition of a physical
item or the contents delivered with a digital listing. Review the source and
license before reuse outside the local catalog.
