# CryptoC2C 项目流程总览

> **状态：历史研究/长期概念参考，非当前实施规格。** 2026-09-06 复核：当前只有前端演示版；市场、法规、成本和技术示例不能直接作为上线依据。适用范围见 [文档入口](../README.md)，已知错误与处置见 [复核记录](../review-corrections.md)。


> 给团队 / 投资人 / 合作方看的 5 分钟简版

## 一句话定义

**CryptoC2C = 海外加密社区的 C2C 二手交易平台 + 链上 escrow 托管 + USDT/ETH 支付**

不做中国大陆,目标全球(欧盟/东南亚/拉美为主)。

---

## 项目生命周期(12-18 月)

```
Phase 0 ─→ Phase 1 ─→ Phase 2 ─→ Phase 3
 调研       MVP         扩展        平台化
 0-2月      3-6月       7-10月      11月+
```

### Phase 0: 调研 + 决策(0-2 月) ⚠️ GO/NO-GO 关卡

**做什么**:
- 社区调研(目标:200+ 真实回复,验证需求)
- 法律咨询(欧盟 / 新加坡律所)
- 智能合约原型(Foundry + OpenZeppelin)
- KYC 流程跑通(测试网)
- 决定**法律主体注册地**

**关键产出**:
- 调研报告(留资邮箱 > 500)
- 律所备忘录
- 合约代码 v0.1
- GO / NO-GO 决策

**预算**: $50-120K

---

### Phase 1: MVP 上线(3-6 月) — 数字商品优先

**为什么先数字商品**:
- 无物流 → 争议少
- 客单价低 → 学习成本低
- 快速验证 PMF(产品市场契合)
- 真实二手实物放 Phase 2

**功能范围**:
- 邮箱注册 + KYC(Sumsub)
- 钱包连接(Wagmi + WalletConnect)
- 商品发布(数字商品 / 账号 / 订阅)
- 站内信
- **链上 escrow(仅 Ethereum L1,USDT/ETH)**
- 订单状态机 + 平台仲裁
- 仅 Web 端,无 App

**关键产出**:
- 智能合约主网部署(已审计)
- Web App 上线
- 1000 个真实用户
- 1000 个真实交易

**团队**: 5.5 人(全栈 2 + Solidity 1 + 产品 1 + 运营 1)
**预算**: $256-552K

---

### Phase 2: 扩展(7-10 月) — 实物 + 多链

**新增能力**:
- 实物二手 + 物流追踪(AfterShip)
- 多链(Arbitrum / Base / USDT-TRC20)
- 评价系统
- 信用分 v1
- 移动端 Web(PWA)

**KPI**:
- 月活 1 万
- 累计 GMV $100 万

**预算**: $410-730K

---

### Phase 3: 平台化(11 月+)

**新增能力**:
- 商家认证 / 店铺
- 拍卖
- 信用分 v2(链上)
- 原生 iOS / Android App
- 盈亏平衡

**KPI**:
- 月 GMV $100 万
- 抽佣收入覆盖运营

## 关键风险(必须早做防护)

| 风险 | 等级 | 防护 |
|---|---|---|
| 智能合约漏洞 | **P0** | 2 家独立审计 + Bug Bounty + 多签暂停 |
| 监管突变(目标辖区禁加密) | **P0** | 多辖区分散 + 法务预算 |
| 私钥泄露(平台) | **P0** | 多签(Safe) + 硬件钱包 + 热钱包限额 |
| 用户增长不达预期 | P1 | Phase 0 验证,有退出策略 |
| 欺诈交易 | P1 | KYC + 信用分 + 大额审核 |
| 大公司(eBay/Amazon)进入 | P2 | 早期社区 + 加密原生定位 |

---

## 核心差异化(我们 vs 闲鱼/eBay)

| 维度 | 闲鱼 / eBay | **CryptoC2C** |
|---|---|---|
| 跨境支付 | 信用卡(3% 跨境费 + 拒付) | **USDT/ETH（费用取决于链、Gas 与平台费）** |
| 信任机制 | 平台托管(中心化) | **链上 escrow(不可篡改)** |
| 用户隐私 | KYC 强 | 原型无认证；真实产品身份要求待专项评估 |
| 抽佣 | 0 / 12% | **1-1.5%**(竞品最低) |
| 服务地区 | 单一国家 | **全球**(除中国大陆) |

**我们的护城河**:**链上 escrow + 加密社区 + 低抽佣**的组合,大公司不愿做(合规成本高,二手市场小)。
