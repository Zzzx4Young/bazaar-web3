# 服务端 Alpha 业务规格

更新：2026-09-13。状态：业务基线已由 I1—I6 实现并验收，当前进入 [I7 受控内测](internal-alpha-testing-plan.md)。产品依据为 [ADR-0002](adr/0002-server-alpha.md) 的 Q1—Q4-10；实现接口见 [OpenAPI](openapi/alpha.json)，实际证据见[阶段记录](backend-stage-report.md)。

## 范围

仅开发内测，预置账户＋密码，服务端身份验证、共享持久化数据与权限控制。实物单件、授权数字内容非独占重复销售。结算全程模拟，不接钱包、合约、真实支付、物流服务、文件托管、邮件登录或仲裁后台。不建设自动订单超时、独立退货流程或完成后售后。

## 订单状态与操作

| 当前状态 | 操作与主体 | 结果及约束 |
|---|---|---|
| 无订单 | 买家创建订单 | 待付款；服务端校验商品可售和买卖双方不同，实物原子占用单件库存 |
| 待付款 | 订单买家取消 | 已取消；释放该订单的实物占用，不能再次模拟付款 |
| 待付款 | 订单买家模拟付款 | 待交付；仅修改模拟状态，无资金转移 |
| 待交付 | 订单卖家提交交付 | 待验收；实物记录物流信息，数字内容记录私有链接及必要提取码 |
| 待交付或待验收 | 订单买家报告问题 | 异常处理中；记录来源状态和问题，不能自动完成 |
| 待验收 | 订单买家确认收到并验收通过 | 已完成；保留只读历史，不提供完成后售后 |
| 异常处理中 | 订单卖家补交 | 保持异常并追加交付记录；不能由卖家直接认定问题解决 |
| 异常处理中 | 订单买家确认问题解决且验收通过 | 已完成；须存在交付记录，记录买家明确确认 |
| 异常处理中 | 订单买家申请全额模拟退款、卖家同意执行 | 已退款；记录双方操作。实物由卖家确认退回结果或同意无需退回，不自动恢复可售 |
| 已取消、已退款、已完成 | 任意重复或不合法状态操作 | 不重复改变状态或库存；按幂等与冲突规则返回结果 |

有分歧时保持异常，由团队线下协调；仍通过合法账户操作处理，不能将直接改数据库作为业务流程。没有普通订单超时任务，无人操作会一直保留状态。异常撤回、部分退款等未纳入本阶段。

## 商品与库存

- 实物创建订单与占用库存必须同时成功或同时失败；并发下只能一个订单占用。取消释放必须绑定原订单，不得释放另一订单库存。
- 全额模拟退款后的实物保持不可售；仅卖家确认货物在手且可再售后手动恢复，保留原退款历史。无需退回不代表可以恢复可售。
- 数字内容不因单次成交耗尽库存；每个订单独立授权查看交付信息。
- 工程草案：分别记录发布状态与库存状态，避免卖家主动下架后因取消订单而被意外重新上架。成交实物保留历史并禁用购买，不硬删除。
- 商品编辑不改变已有订单约定；编辑、下架不撤销现有订单，也不释放其库存占用。

## 权限与私有数据

| 数据或操作 | 允许主体 |
|---|---|
| 可售商品公开字段 | 浏览者；不得包含收件信息、交付链接、提取码或密码数据 |
| 发布商品 | 已登录测试账户 |
| 编辑、下架、退款后恢复商品 | 商品所属卖家，且满足状态约束 |
| 查看订单、交付信息和操作历史 | 该订单买家与卖家 |
| 模拟付款、取消未付款订单、报告问题、验收 | 该订单买家 |
| 提交交付、补交、同意模拟退款 | 该订单卖家 |

前端隐藏按钮不代替服务端鉴权。内测也不将明文密码写入前端或仓库；登录退出、会话有效期、密码安全存储及请求防护在技术规格中展开。

## 订单快照与最小数据模型

建议实体：Account、Listing、Order、DeliveryRecord、IssueRecord、OrderEvent、Session。数据库方向已确认为 PostgreSQL，ORM 已选 Prisma；具体字段及 schema 待设计，见 [后端架构](backend-architecture.md)。

- 创建订单时固定商品 ID、买卖双方 ID、商品类型、标题、描述、价格与币种；数字内容同时固定卖家提供的授权说明和版本标识。金额使用精确表示，不使用浮点运算或跨币种直接比较。
- 私有收件信息与公开商品字段分离；交付链接、提取码仅保存到相应订单的交付记录。敏感值不进入普通日志。
- 补交追加版本与操作时间，不静默覆盖原交付记录；保留问题、退款请求、卖家确认和库存恢复的操作记录。
- 快照只能保存当时约定及链接文本，不能固定或验证第三方文件内容，也不能保证外部链接持续有效或阻止转发。
- 已完成订单买卖双方可读取历史交付记录，不代表平台承诺外部链接永久可用。

## 业务验收

1. 账户与商品：独立浏览器分别登录，发布后另一账户可见；只有所属卖家可编辑/下架；服务重启后数据保留。
2. 订单与库存：验证并发抢购仅一单成功、重复取消不会重复释放、已取消不能付款、越权请求被拒绝。
3. 两类交付：分别验证物流信息和私有链接交付，买家先验收再完成；未授权账户无法通过直接请求读取交付数据。
4. 异常与退款：报告问题、补交、买家验收或双方退款；退款不自动恢复实物可售，卖家手动恢复不改变历史订单。
5. 终态与数据：完成后无售后操作，商品编辑不改变订单快照，重复请求和失败重试不破坏一致性。
