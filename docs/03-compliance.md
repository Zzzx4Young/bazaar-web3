# 03. 合规清单

> ⚠️ **重要声明**: 本文档**不构成法律建议**。涉及具体司法管辖区的牌照、税务、监管细则,必须聘请当地专业律所确认。本文基于 2025 年中公开信息整理,2026 H1 后的变化未覆盖。

## 1. 合规原则

1. **明确不服务中国大陆用户** — IP 屏蔽 + 协议禁止
2. **KYC 必须** — 任何涉及资金转移的用户必须 KYC
3. **AML 必须** — 大额/可疑交易上报
4. **数据本地化** — 遵循用户所在司法管辖区
5. **可审计** — 所有链上行为有据可查

- **屏蔽**: 中国大陆 IP + 美国 + 受限国家

## 3. 必须遵守的核心法规

### 3.1 反洗钱(AML / CFT)

| 要求 | 实施 |
|---|---|
| **KYC(了解你的客户)** | 所有入金用户必须 KYC(身份证 + 自拍 + 地址证明) |
| **可疑交易报告(STR)** | 单笔>$10K 或可疑模式必须上报 |
| **大额交易报告(CTR)** | 单笔>$10K 上报 |
| **交易记录保存** | 至少 5 年 |
| **旅行规则(Travel Rule)** | 跨机构转账附发起人/受益人信息(>$1K) |
| **OFAC / 制裁名单检查** | 任何用户必须过制裁名单(SDN) |

**实施工具**:
- KYC: **Sumsub**, **Onfido**, **Persona**, **Jumio**(任选)
- 制裁名单检查: **Chainalysis**, **Elliptic**, **TRM Labs**

### 3.2 支付服务 / 加密货币牌照

| 司法管辖区 | 需要牌照 | 备注 |
|---|---|---|
| 欧盟 | **MiCA CASP**(加密资产服务提供商) | 2024-2025 全面生效 |
| 新加坡 | **MAS PSA** Major Payment Institution | 申请周期 6-12 月 |
| 英国 | **FCA Cryptoasset Registration** | 申请周期 6-12 月 |
| 澳大利亚 | **AUSTRAC DCE** 注册 | 较快 |
| 瑞士 | **FINMA Fintech License** 或 Banking License | 较贵 |
| 加拿大 | **FINTRAC MSB** | 注册即可,但各省另有要求 |
| 美国 | **FinCEN MSB** + 各州 MTL/NML/CDF | **最复杂** |

**建议**:
- **MVP**: **爱沙尼亚 MiCA CASP** + **新加坡 MAS PSA**(选择性)
- **年成本**: 律师费 $50-150K + 牌照费 $20-50K + 年合规运营 $100-300K

### 3.3 消费者保护(电商法)

- **GDPR**(欧盟)
  - 用户数据删除权
  - 数据泄露 72 小时报告
  - 隐私政策 + Cookie 同意
- **消费者退货权**(欧盟 14 天)
- **商品描述真实性**
- **争议解决**

### 3.4 数据保护与隐私

| 法规 | 适用 | 要求 |
|---|---|---|
| GDPR | 欧盟用户 | 数据保护官 / 隐私政策 / 数据本地化 |
| CCPA | 加州用户 | 隐私政策 / 数据访问权 |
| LGPD | 巴西用户 | 类似于 GDPR |
| PDPA | 新加坡/泰国 | 数据保护 |

**实施**:
- 数据加密(at rest + in transit)
- 数据本地化(欧盟用户数据存欧盟)
- 隐私设计(Privacy by Design)
- 用户数据导出 / 删除接口

### 3.5 税务

**CryptoC2C 平台税务责任**:
- 不直接处理用户税务(用户自报)
- **可能**需要向税务机关报告大额交易(>10K USD 等价)
- 跨境交易需关注 VAT / GST

**用户税务责任**:
- 二手物品交易一般无 VAT
- 加密货币买卖可能产生资本利得税(用户自报)
- 平台**提供交易历史**给用户(供报税用)

## 5. 中国大陆合规(明确拒绝)

**为什么不做大陆**:
1. **十部委 2021 通知**: 禁止虚拟货币作为支付工具
2. **2024 进一步政策**: 跨境加密支付被严控
3. **《刑法》225 条**: 非法经营罪可适用
4. **平台责任**: 大陆用户出现,平台面临连带

**具体落实**:
- **IP 屏蔽**: 中国大陆 IP 无法访问
- **协议禁止**: 用户协议明确"中国大陆居民不得使用"
- **KYC 拒绝**: 中国大陆身份证 / 手机号直接拒绝
- **退款**: 一旦发现大陆用户,关闭账户并退还余额(扣手续费)

## 6. 风险揭示(给用户)

平台应在显眼位置展示:
> "使用加密货币进行交易存在以下风险:
> - 价格波动: 加密货币价格可能在交易期间剧烈波动
> - 不可逆: 链上交易一旦确认,无法撤销
> - 监管风险: 各国对加密货币的监管不同,可能影响您的资产
> - 平台风险: 平台可能被监管要求关闭
> - 技术风险: 智能合约可能存在漏洞"
