# 08. 盈利模式

## 1. 收入来源

### 1.1 主要收入:交易抽佣(escrow fee)

**机制**:
- 卖家发布商品免费
- 买家支付时,escrow 合约**自动扣除** 1-2% 给平台
- 卖家收到 98-99%

**费率设计**:
| 用户等级 | 抽佣率 | 备注 |
|---|---:|---|
| 普通用户 | 1.5% | 默认 |
| 认证商家(Phase 3) | 1.0% | 高频 |
| 高 GMV 用户 | 0.8% | 谈判 |
| 长期用户 | 0.5% | 激励 |

**对比**:
| 平台 | 抽佣 |
|---|---:|
| eBay | 12.9% + $0.30 |
| Etsy | 6.5% |
| Poshmark | 20%(前 $15) |
| OpenSea | 2.5% |
| **CryptoC2C** | **1-1.5%** |

**我们的优势**: 抽佣低,**对加密用户有吸引力**。

### 1.2 次要收入

| 来源 | 说明 | 时间 |
|---|---|---|
| **推广 / 流量** | 商家付费置顶(类似 eBay) | Phase 3 |
| **数据 / API** | 卖交易数据(脱敏后)?⚠️ 合规风险 | 不做 |
| **白标服务** | 其他平台用我们的 escrow 技术 | 长期 |
| **会员费** | Pro 用户(免抽佣 + 高级功能) | Phase 3 |
| **广告** | 商品 / 类目赞助位 | Phase 3 |

## 3. 单位经济(Unit Economics)

### 3.1 每笔交易经济

**假设**:
- 平均订单金额:$100
- 抽佣率:1.5%
- 收入/单:**$1.50**

**成本/单**:
- 链上 gas(用户付):$0
- 链上分析:$0.50
- KYC 分摊(假设 1 年摊销):$0.20
- 客服分摊:$0.10
- 服务器分摊:$0.10
- **总成本/单**:**$0.90**

**单笔毛利**:**$0.60**(毛利率 40%)

**注意**:
- **用户付 gas**,**平台不付**
- KYC 是**一次性**成本,后续分摊
- 客单价高的订单,边际成本几乎为 0

### 3.2 用户生命周期价值(LTV)

**假设**:
- 用户月均交易:2 笔
- 用户生命周期:12 月
- 单笔毛利:$0.60
- **月毛利/用户**:**$1.20**
- **年 LTV**:**$14.40**

**问题**: LTV 太低,**难以覆盖 CAC**。

**改进**:
- 提高客单价(鼓励高价值商品)
- 提高交易频次(社交化,推荐)
- 增值服务(Pro 会员)

### 3.3 改善后

| 场景 | 客单价 | 月频次 | 月毛利/用户 | 年 LTV |
|---|---:|---:|---:|---:|
| 数字商品(账号) | $50 | 3 | $2.25 | $27 |
| 中等实物 | $200 | 2 | $6.00 | $72 |
| 高价值(收藏) | $1000 | 0.5 | $7.50 | $90 |
| **加权平均** | **$300** | **1.5** | **$6.75** | **$81** |

**目标**: 1 万月活用户,LTV $80 = **年 LTV 总和 $960 万**

## 4. 盈亏平衡分析

### 4.1 固定成本假设

月度固定成本 $60K(取中间值)

### 4.2 盈亏平衡交易量

```
月度盈亏平衡交易量 = 月度固定成本 / 单笔毛利
= $60,000 / $0.60
= 100,000 笔/月
```

**或以 GMV 计**:
```
月度盈亏平衡 GMV = $60,000 / 1.5% = $4,000,000
```

**含义**: 需要**月度 GMV 400 万美元**才能盈亏平衡。

**对比**:
- eBay 月 GMV 几十亿
- 闲鱼月 GMV 数十亿
- 我们要 400 万 GMV,大概是 4-8 万用户,客单价 $50-100

**现实**: Phase 3 才可能达到。

## 6. 替代盈利路径(Plan B)

如果 Plan A(抽佣)不可行:

### Plan B1: 增值服务

- **Pro 会员**: $9.99/月,免抽佣 + 优先客服 + 高级搜索
- 类似 Amazon Prime 思路

### Plan B2: B2B 工具

- 卖 **escrow-as-a-service** 给其他 C2C 平台
- 类似 Stripe Connect
- **白标 + API**

### Plan B3: 数据/分析

- 卖**行业洞察**(脱敏后)
- 给对冲基金 / 营销公司
- ⚠️ 合规风险高

### Plan B4: 退出

- 被 eBay / Coinbase 收购
- 估值: 5-20x ARR
- **最低退出** $1000 万 ARR(2-3 年)

## 10. 风险与缓解(财务视角)

| 风险 | 影响 | 缓解 |
|---|---|---|
| 抽佣过低 | 收入不足 | 增值服务 |
| 用户增长慢 | 现金流 | 控制成本 |

| 监管罚款 | 大额 | 法律预算 |
| 链上事故 | 灾难 | 审计 + 保险 |
