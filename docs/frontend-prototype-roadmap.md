# 前端演示版路线与验收

状态：当前 Demo 功能基线。更新：2026-09-08。决策来源：[ADR-0001](adr/0001-frontend-prototype-first.md)、[2026-07-31 决策记录](archive/changelog-before-cleanup.md)。已选择 Next.js / React、shadcn/ui，以及保留历史 MVP 方案的 B 路线；不再等待 Q1/Q3/Q4。

## 目标与边界

验证 C2C 实物、数字商品市场的浏览、筛选、发布、收藏和订单展示体验。所有交易是模拟；没有真实钱包、后端、合约、登录、资金转移、交付或退款。

价格支持 CNY / USDT / ETH / SOL 仅表示演示计价，不表示接入了这些支付渠道。NFT、域名等样例仅用于卡片展示，不代表确定的可交易品类或权利转移能力。

## 当前架构与页面

Next.js App Router 的服务端布局提供语言与主题上下文，交互组件在客户端读取 Mock 数据和浏览器本地存储。默认中文，另有英文路由；部分业务文案尚未翻译。

所有页面位于 `/{locale}` 下，locale 为 `zh-CN` 或 `en`；`/` 重定向 `/zh-CN`。

| 路由后缀 | 当前能力 |
|---|---|
| `/` | Banner、分类入口、精选/实物/数字网格，合并本地发布商品 |
| `/explore` | 关键词、一级分类、实物/数字、币种、成色、排序；分类入口读取 URL 参数 |
| `/listing/[id]` | 商品媒体、Markdown、卖家、收藏、模拟聊天和模拟购买；刷新后恢复本地商品 |
| `/publish` | 实物/数字、一级分类、字段校验、占位图；保存成功跳转同语言详情 |
| `/me` | 固定演示用户资料、买卖订单 |
| `/seller/[id]` | 演示卖家资料、静态及本地发布商品 |
| `/favorites` | 收藏商品及导航计数，同页组件即时同步 |
| `/notifications` | 静态示例通知 |

## 本轮修正的验收目标

1. 发布商品可在详情、首页、探索、卖家页、收藏及订单关联中读取，刷新不丢失。
2. 详情等待本地数据恢复后再判断本地商品是否存在；其他浏览器不能访问仅保存在本机的发布内容。
3. 一级分类准确区分电子数码/服饰，以及数字资产/源码/游戏；新商品明确填写分类。
4. 收藏变化同步到当前页面的多个组件，并响应其他标签页的 storage 事件。
5. 发布字段校验展示到相应字段；存储失败不显示保存成功。
6. 站内链接保持语言；导航包含个人中心；模拟下单的“查看订单”实际跳转。
7. 全局提示演示边界，购买界面不声称已调用钱包、合约或已锁定真实资金。
