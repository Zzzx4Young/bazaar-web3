# ADR-0002 — 内部服务端 Alpha，结算保持模拟

状态：已接受。日期：2026-09-08。决策人：项目负责人。

## 背景

前端 Demo 已能展示基本交互，下一阶段验证共享数据和多用户权限。用户选择服务端 Alpha，逐项确认以下范围，并确认业务规格作为当前基线。

## 决策摘要

| ID | 用户决定 |
|---|---|
| Q1 | A：服务端 Alpha，结算模拟 |
| Q2 | 实物二手与授权数字内容同时支持 |
| Q3-1 | B：仅开发内测，不开放注册、外部邀请 |
| Q3-2 | A：预置账户＋密码，服务端登录、退出和鉴权 |
| Q4-1 | A：实物单件，授权数字内容非独占重复销售 |
| Q4-2 | A：卖家自行寄送并提供单号，买家自行查询确认；平台不提供物流，内测虚拟数据 |
| Q4-3 | A：订单内外部链接与必要提取码，平台不托管文件 |
| Q4-4 | A：模拟付款后卖家手动交付，买家先验收再完成 |
| Q4-5 | A：双方处理补交或全额模拟退款，分歧线下协调，订单保持异常，不建仲裁后台 |
| Q4-6 | A：暂不自动超时，无人操作保留状态 |
| Q4-7 | A：创建实物订单占用库存，买家取消未付款订单后释放 |
| Q4-8 | A：实物退款后不可售，卖家确认货物在手且可售后手动恢复 |
| Q4-9 | A：线下协调退回，卖家确认结果或同意无需退回后执行模拟退款 |
| Q4-10 | 接受 A：无完成后售后入口，保留只读历史，问题线下记录 |

## 影响

- 取代 [ADR-0001](0001-frontend-prototype-first.md) 中仅停留前端的阶段限制，保留其历史理由。
- 公开部署、外部试用、真实交易、钱包、合约和链选择未纳入本阶段；账号、NFT、域名等 Demo 样例不自动成为支持品类。
- 内测选择不是市场需求、支付安全或法律适用性的验证，无完成后售后不作为未来商业规则。
- 不恢复旧测试网工单或估时。业务细则只维护在 [业务规格](../server-alpha-spec.md)，实施顺序只维护在 [执行计划](../execution-plan.md)。
