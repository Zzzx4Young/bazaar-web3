## I5 推进顺序

2026-09-13 复核修复：I5 前端异常流程和验收证据已补正。订单页读取交付/问题/退款/结算/事件，支持数字提取码、两类问题、实物退货结果及恢复；结果未知命令可跨刷新同键重试。浏览器使用真实订单 ID 验证第三账户 404，并完成实物退款/恢复。修复提交 `f515080` 的远端 CI 已通过，I5 正式完成并进入 I6 交接。

1. 前置复核：补齐商品编辑/下架、会话失效和退出失败处理、同源请求与错误提示；把 Demo 与后端事实边界落实到界面和测试。验证两个账户的所有权与服务重启恢复。
2. 订单读取与下单：真实参与方列表/详情、精确金额字符串、实物收件快照；不将浏览器 Demo 订单迁入服务端。
3. 正常交付：模拟付款、实物物流/数字链接及提取码、明确确认验收；链接仅展示，打开使用 noopener/noreferrer。
4. 异常流程：问题、补交、退款申请、卖家退款、实物恢复；一次动作保持同一幂等键和请求内容，结果不明时同键重试，成功后重新读取状态。
5. 出口：实物和数字分别完成成交及异常退款；独立浏览器验证越权和私有数据、断网重试及竞争；使用专用测试库和随机账户自动清理，运行前端类型/Lint/单元/构建/E2E。通过后进入 I6 全量回归与内测交接。
