# Alpha 纵向实现工单

更新：2026-09-12。C1 已验收；CI 配置已完成、远端未运行；C2/C3 为工程契约。以下工单尚未实现，不提供未经测量的工期。顺序为 I1 → I2 → I3 → I4 → I5 → I6，完成一项记录命令、结果与限制，再推进下一项。

| 工单 | 交付 | 验收与失败处理 |
|---|---|---|
| I1 认证与请求边界 | 凭据/Session 追加迁移、scrypt、显式账户预置、会话读取/退出、Origin/CSRF、登录限流、安全异常映射、角色授权 | 正确/错误/禁用登录，Cookie 与过期/撤销、服务重启保留会话；伪造 Origin/CSRF/身份拒绝，无泄漏；无默认密码，预置失败整批回滚，重复登录名不覆盖 |
| I2 商品服务 API | 公开/自己列表与详情、原子创建商品/实物库存、版本编辑/下架、19 币种精度、汇率快照与 USD 参考价分页排序 | A 发布 B 可读、B 不可编辑、下架只自己可见；失败无半个库存；数字无库存；跨币种顺序、快照分页、汇率不可用、金额精度、版本竞争和隐私 DTO；完整后端回归 |
| I3 前端账户/商品联调 | 同源 API 代理、登录/退出、内存会话状态、真实商品列表/详情/发布/编辑；语言目录文案；移除这些流程对浏览器本地商品事实的依赖 | 两个独立浏览器登录预置账户，A 发布 B 可见；错误保留表单、退出清理私有 UI、失效会话跳转；生产构建、类型、Lint、单元与 Playwright；数据库重启后商品保留 |
| I4 订单服务 HTTP | 参与方查询/分页、动作 DTO、幂等头、结构化交付新增字段、金额快照输出；复用 C1 命令 | HTTP 越权矩阵、非法 DTO、补交/退款/恢复；真实并发与回放仍正确；升级历史交付可读；私有信息不进公开响应；受限运行账号全流程 |
| I5 前端订单与两类交付 | 下单收货、模拟付款、卖家交付、买家验收、问题/退款、恢复、私有历史；保持动作幂等键 | 实物和数字各一条成交、一条异常退款；竞争仅一方成功；断网结果不明同键重试；其他账户直接请求看不到链接/地址；不把 Demo 本地订单静默当真实订单 |
| I6 集成与内测交接 | 浏览器 E2E 入 CI、完整回归、启动说明、可复现测试账户预置流程和已知限制 | 全部 Alpha 业务验收、类型/Lint/单元/构建/E2E；最终所有迁移 DB-10；停止专用验证容器保留卷；远端 CI 只在真实运行后记录通过 |

I1/I2 的数据库迁移只追加，不改已执行历史。I3/I5 需使用真实后端和专用测试库运行 E2E，不能用 mock 拦截证明联调成功。预置测试密码仅在临时受限文件生成/传递，不提交，不写到前端构建参数。

图片上传、真实支付、对外部署、注册、聊天室、完整通知系统不自动追加到上述工单。现有 Demo 范围之外的 UI 只调整对完成 Alpha 流程确有必要的部分；头像/商品占位图不需要引入文件托管。
