# 内测问题记录模板

复制以下字段记录一个问题。只填写测试角色和虚拟数据标签，不粘贴密码、Cookie、
CSRF、完整收件信息、数字链接、提取码、数据库连接串或未经检查的原始日志。

- 标题：
- 严重程度：阻塞 / 严重 / 一般
- Commit SHA：
- 环境：操作系统、浏览器、Node/npm/PostgreSQL 版本
- 账户角色：卖家 / 买家 / 外部账户
- 前置订单或商品状态：
- 操作步骤：
- 预期结果：
- 实际结果及公开错误码：
- `X-Request-Id`：
- 是否可稳定复现：
- 已检查且可安全共享的截图或日志位置：
- 临时替代步骤：
- 修复提交与回归结果：
