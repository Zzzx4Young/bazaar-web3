# 01. 产品概述

> CryptoC2C — 加密支付驱动的全球二手交易平台

## 1. 一句话定义

**CryptoC2C 是一个面向海外加密社区的 C2C 二手物品交易平台,以 USDT/ETH 等加密货币为支付手段,通过链上 escrow(托管)解决陌生人信任问题。**

## 2. 产品定位

### 2.1 我们不做什么

| 不做 | 原因 |
|---|---|
| ❌ 数字藏品 / NFT 交易 | 已有 OpenSea、Blur 等成熟玩家,我们无差异化 |
| ❌ 全新商品 B2C 销售 | 已有 Amazon、Shopify 等巨头 |
| ❌ 中国大陆用户 | **明确违法** |
| ❌ 加密货币兑换/OTC | 涉及金融牌照,合规风险极高 |
| ❌ 自营仓储/物流 | 重资产,二手交易不需要 |

### 2.2 我们做什么

| 做 | 说明 |
|---|---|
| ✅ 二手物品(实物)C2C 撮合 | 类似 eBay、闲鱼、Poshmark |
| ✅ USDT/ETH 链上支付 | 主流稳定币 + 主流币 |
| ✅ 链上 escrow 托管 | 解决陌生人交易信任问题 |
| ✅ 争议解决 | 平台仲裁 |
| ✅ 全球用户 | **目标海外**,地理多元 |

### 2.3 核心价值主张

```
传统二手平台(闲鱼/eBay):
  买家 ─(法币)→ 平台 ─→ 卖家
  问题:跨境支付难(信用卡费率/拒付/退款)、法币出入金慢

CryptoC2C:
  买家 ─(USDT/ETH)→ 智能合约 escrow ─(确认收货)→ 卖家
  优势:跨境无障碍、无拒付、几分钟到账
```

## 3. 目标用户

### 3.1 主用户:加密原生用户(海外)

| 维度 | 描述 |
|---|---|
| **地理** | 东南亚(菲律宾、越南、泰国)、拉美(阿根廷、墨西哥)、非洲(尼日利亚、肯尼亚)、东欧(乌克兰、土耳其)、西欧(德国、英国) |
| **年龄** | 25-40 岁 |
| **特征** | 持有 USDT/BTC/ETH,有跨境支付需求(汇款、网购),对加密支付有基本信任 |
| **行为** | 日常使用 Binance / OKX / Coinbase,熟悉钱包操作 |
| **规模** | 全球 ~5 亿持币人,其中**真用加密做日常支付的 5-10%** = **目标 25-50 万活跃用户** |

### 3.2 次用户:跨境电商卖家/买家

| 维度 | 描述 |
|---|---|
| **卖家** | 中国/东南亚/欧洲卖家,卖往全球(规避 SWIFT 高费率) |
| **买家** | 不想用信用卡(隐私/拒付风险)的人,或来自"信用卡渗透率低"的国家 |

### 3.3 不服务的用户

- ❌ 中国大陆居民
- ❌ 完全无加密经验的用户(学习成本太高)
- ❌ 高客单价($1000+)用户(更适合专业拍卖/电商)

## 4. 核心场景

### 4.1 主要场景

#### 场景 A: 跨境二手交易

```
Alice(德国,持 1000 USDT)想买一台二手 iPhone
Bob(美国,iPhone 卖家)要 800 USDT
  1. Bob 在 CryptoC2C 发布 iPhone,标价 800 USDT
  2. Alice 浏览、联系 Bob
  3. Alice 通过平台 escrow 锁仓 800 USDT
  4. Bob 看到 escrow 锁定,发货
  5. Alice 收到货,确认,escrow 释放给 Bob
  6. 完成
```

**价值**: 相比 PayPal / 信用卡,**无 3% 跨境费率**,**无拒付风险**,**几分钟到账**。

#### 场景 B: 数字商品 / 订阅账号交易

```
Charlie 想买一个 ChatGPT Plus 1 年账号
Dana 持有一个 Team 账号想出售
  1. Dana 发布账号信息,标价 200 USDT
  2. Charlie 下单,escrow 锁定
  3. Dana 修改账号密码或提供邀请链接
  4. Charlie 验证,确认
  5. 释放
```

**价值**: 信用卡拒付高,**加密支付无拒付**,**卖家更愿意接**。

#### 场景 C: 实物收藏品(手表、潮玩)

```
Eduardo(阿根廷)想收藏一只 Rolex
Frank(香港)卖闲置手表
  1. Frank 发布手表
  2. Eduardo 选购,escrow 锁定 5000 USDT
  3. Frank 发顺丰国际
  4. Eduardo 验货,确认
  5. 释放

注:阿根廷外汇管制严,信用卡难,**USDT 是替代方案**
```

### 4.2 次要场景

- 数字产品(模板、代码、素材)的二手销售
- 服务交易(翻译、设计)的 escrow
- 域名 / 社交账号的 escrow

## 6. 与现有产品的差异

| 维度 | 闲鱼 | eBay | OpenSea | Bidali | **CryptoC2C** |
|---|---|---|---|---|---|
| 二手实物 | ✅ | ✅ | ❌ | ⚠️(礼品卡) | ✅ |
| 加密支付 | ❌ | ❌ | ✅(链上) | ✅ | ✅ |
| 数字商品 | ⚠️ | ⚠️ | ✅(NFT) | ❌ | ✅ |
| 实物 escrow | ❌(用闲鱼币) | ✅(托管) | ❌ | ❌ | ✅(链上) |
| 跨境无障碍 | ❌ | ⚠️ | ✅ | ⚠️ | ✅ |
| 平台抽佣 | 0 | ~12% | 2.5% | ~3% | **目标 1-2%** |
| 信任机制 | 平台信用 | 平台信用 | 智能合约 | 平台信用 | **智能合约 + 平台** |

**核心差异**:
1. **链上 escrow + 法币入金低费率的组合** — 不被传统电商 + 信用卡抽佣压垮
2. **全球用户** — 不限于地理
3. **抽佣比 eBay / OpenSea 低** — 卖点

## 7. 不做的功能(明确排除)

- ❌ **法币入金/出金** — 涉及金融牌照,我们只接加密
- ❌ **加密货币兑换** — 涉及兑换牌照
- ❌ **借贷 / 抵押** — 复杂金融业务
- ❌ **代币发行** — 任何形式的 ICO / IEO
- ❌ **中国大陆 IP / KYC** — 强制屏蔽

## 8. 产品原则

1. **用户资产优先** — escrow 合约开源、审计、不持有用户私钥
2. **合规优先** — 严格 KYC/AML,宁可慢不要出事
3. **透明费率** — 所有费率在用户操作前明示
4. **去中心化程度可控** — 链上 escrow 必须,撮合 / 仲裁可中心化
5. **Web3 体验简化** — 用账户抽象(ERC-4337)降低门槛
